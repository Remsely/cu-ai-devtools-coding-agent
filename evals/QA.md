# Проверка сдачи

## Автоматические проверки

На Python 3.14 / Windows, с Git Bash в PATH:

```text
python -m pytest tests -q --tb=short
134 passed in 5.78s
```

Из них 47 — существующий runtime, 56 — AgentLens и его CLI, 9 — калибровка
независимых проверок, матрица опыта и аргументы Docker-изоляции, 22 —
агрегация результатов и проверка сопоставимости/происхождения данных.
`git diff --check` не обнаруживает проблем с пробелами.

## Обязательный анализ без сети

Отдельно выполнен `python -B -S -m agentlens analyze --input /data --json`
в чистом образе Python 3.12 slim с `--network none`, read-only root, без
capabilities. Монтировались только пакет agentlens и реальные журналы discovery,
оба только для чтения; agent/, .env, домашний каталог и API-ключи не передавались.
Результат программно разобран как JSON:

```json
{
  "files_seen": 3,
  "sessions_analyzed": 3,
  "sessions_with_repeats": 2,
  "executions": 43,
  "failed_executions": 32,
  "unknown_executions": 0,
  "uncomparable_failures": 0,
  "repeat_episodes": 6,
  "repeated_failures": 18,
  "incomplete_sessions": 0
}
```

Сохранены настоящие примеры stdout для одной сессии и каталога в текстовом и
JSON-формате. Проверены `--help`, отсутствие находок, повреждённый/нечитаемый
вход, раздельные stdout/stderr и ненулевые коды ошибок. Подробности ограничений
метода и ручная сверка неуспеха находятся в README и MANUAL_CHECK.md.

## Среда

Для исходных и сравнительных запусков использована локальная Ollama,
qwen3.5:9b, 65536 токенов контекста, think=false, temperature=0.2.
Сохранены digest модели и image ID. Первоначально Docker Desktop не запускался
из-за устаревших временных Unix socket-файлов; socket-каталоги сохранены под
резервными именами, данные Docker не сбрасывались. Это подготовка среды до
сравнения, не исключённая неудачная попытка агента.

## Финальный аудит материалов

Подтверждены 15 уникальных реальных сессий: 3 исходные и 12 сравнительных.
Повторный AgentLens-разбор всех журналов завершён без ошибок и неполных
командных результатов. Отчёт A/B подтвердил сбалансированную матрицу и
сопоставимость сохранённых условий без замечаний. Проверены локальные ссылки
новой документации, 15 архивов только с исходниками agent/*.py и отсутствие
.env среди материалов. Все ошибки API и неуспешная попытка сохранены.

Перед публикацией повторно исполнен независимый grader для всех 12 финальных
проектов в Docker без сети: совпали статусы и все отдельные проверки.
Интерактивный маршрут «задача → план → y → status/tasks/diff → exit» проверен
на временной копии через scripted-модель; это проверка интерфейса, не новая
реальная сессия эксперимента. Добавлены регрессии на переполнение JSON-чисел,
непарные Unicode-суррогаты, некорректный error.code и разрыв цепочек при
несопоставленных/неоднозначных событиях. Метрики реальных сессий не изменились.
