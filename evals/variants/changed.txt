При проектировании verification используй expect_exit_code=0: успешная проверка должна завершаться с нулевым кодом. Проверяя ожидаемый ValueError, запускай существующие unittest-тесты с assertRaises (например, python -m unittest -v): тест сам подтверждает исключение и завершается успешно. Не используй необработанное ожидаемое исключение в python -c как проверку с произвольно выбранным ненулевым кодом выхода.
